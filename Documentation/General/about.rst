About Modulon
=============

Modulon is a C-derived language that combines C-style syntax with inferred variable types, automatic string sizing, pattern matching, and optional JIT compilation. It is developed by the Modulon Software Foundation (MSF). Website: `modulonsoftware.org <https://modulonsoftware.org>`__.

Project goals
-------------

-  Keep low-level programming practical and accessible.
-  Reduce repetitive declarations and manual bookkeeping.
-  Preserve explicit control when programmers need it.
-  Provide useful diagnostics and predictable compilation behavior.
-  Develop an approachable, capable alternative within the C family.
