Glossary
========

**AOT**
    Ahead-of-time compilation; writes a native executable before running.

**AST**
    Abstract syntax tree; the internal representation of parsed code.

**ABI**
    Application binary interface; conventions for sizes, calling
    sequences, symbols and object layout on a target platform.

**ELF**
    Executable and Linkable Format; the on-disk format used by this
    compiler's native executable and i386 object output.

**Expression**
    Code that calculates a value or performs an operation.

**Freestanding**
    An environment that may not provide the usual operating-system
    process runtime or full C library, such as a kernel.

**Initializer**
    An expression or brace-list supplying a declaration's first value.

**JIT**
    Just-in-time compilation; generates code in memory and runs it.

**Local variable**
    A variable declared inside a function; the native backend normally
    allocates it in that function's stack frame.

**Match arm**
    A pattern, optional guard and statement or expression associated
    with a ``match`` construct.

**Pointer**
    A value representing an address in memory.

**Type inference**
    The compiler determining the type of a local ``var`` from its
    initializer at compile time.

**Wildcard**
    ``_`` or ``default`` as a match pattern covering remaining values.
