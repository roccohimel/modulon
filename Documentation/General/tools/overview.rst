Tools
=====

This repository builds its tools directly from source, with a compact
Makefile-based workflow. The compiler includes an internal assembler and
can invoke an in-process JIT.

- `Compiler executable <tools-compiler.rst>`__
- `Makefile and build flags <tools-make.rst>`__
- `Internal assembler <tools-assembler.rst>`__
- `lines.sh utility <tools-lines.rst>`__

For usage of the language compiler itself, see the detailed
`Compiler section <../compiler/overview.rst>`__.
