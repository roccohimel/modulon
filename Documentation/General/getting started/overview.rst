Getting Started
===============

Modulon source uses the ``.mlon`` extension. The compiler in this repository
builds with a standard C toolchain on a POSIX-like system. The steps here
assume a shell, ``make``, and a working C compiler.

#. `Installation <install.rst>`__: build ``bin/mlonc``.
#. `Hello World <learn-hello.rst>`__: create a complete program.
#. `Compiling and running <workflow.rst>`__: AOT, JIT and assembly output.

Once the basics work, see `Language <../language/overview.rst>`__ and
`Compiler <../compiler/overview.rst>`__.
