Variables
=========

Variables hold typed values. Modulon has explicit C-style declarations
and inferred ``var`` declarations for local storage.

- `Declarations <declarations.rst>`__: ``var`` and explicit types
- `Initialization <initialization.rst>`__: values, arrays and defaults
- `Local and global scope <scope.rst>`__: name resolution and limitations
- `Assignments <assignment.rst>`__: updating values, increment and addresses

For details on where variables live, see `Stack storage <../memory/stack.rst>`__.
