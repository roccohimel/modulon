Examples and Practice
=====================

Examples are useful for checking exact syntax against a specific compiler
revision. This section includes complete runnable snippets and commentary
on the examples already in the repository.

- `Guided examples <guided.rst>`__: small complete programs, step by step
- `Repository examples <repository.rst>`__: what each shipped program shows
- `Exercises <exercises.rst>`__: tasks you can extend and test

For the fastest start, compile one of the complete programs with::

   ./bin/mlonc sample.mlon -o sample
   ./sample

Where appropriate, ``./bin/mlonc --jit sample.mlon`` can run the same
sample directly. Always compare with `Current limitations <../compiler/limitations.rst>`__.
