Learn Modulon
=============

These pages cover the language in the order most people meet it. Each one stands alone, so you can also jump straight to a topic. Familiarity with C helps, because Modulon keeps C’s model and changes the parts that cause friction.

#. `Hello World <learn-hello.rst>`__: your first program and the ``.mlon`` extension.
#. `Variables <learn-variables.rst>`__: ``var`` and type inference.
#. `Types <learn-types.rst>`__: C types, consistency across targets, and ``typeof``.
#. `Strings <learn-strings.rst>`__: automatic sizing and byte counting.
#. `Memory management <learn-memory.rst>`__: compile-time management and manual control.
#. `Pattern matching <learn-match.rst>`__: ranges and the wildcard case.
#. `Operators <learn-operators.rst>`__: ``&&`` and ``||``.
#. `Input and output <learn-io.rst>`__: ``printf``, ``%v`` and ``input``.
#. `Include and define <learn-directives.rst>`__: Modulon’s replacement for the preprocessor.
#. `AOT and JIT <learn-compilation.rst>`__: two ways to run a program.
#. `Assembler <learn-asm.rst>`__: low-level code in the same toolchain.

.. note::

   Code on these pages follows the intended syntax described by the project. If a sample does not compile on your revision, compare it with the programs in `examples/ <https://github.com/roccohimel/modulon/tree/master/examples>`__.
