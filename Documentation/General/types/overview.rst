Types
=====

A type determines how a value is represented, how much storage it takes,
and which operations are valid. Modulon supports basic C-style types with
compiler-specific aliases and some limitations.

- `Built-in types <builtins.rst>`__
- `Type inference <inference.rst>`__
- `Pointers and arrays <pointers-arrays.rst>`__
- `Strings <strings.rst>`__
- `Structures and typedef <structs.rst>`__
- `typeof and sizeof <inspection.rst>`__
- `Type sizes and target differences <portability.rst>`__

See also `Variable declarations <../variables/declarations.rst>`__ and
`Memory <../memory/overview.rst>`__.
